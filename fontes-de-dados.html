Fontes de dados

O Horizonte não coleta nenhum dado próprio — tudo aqui vem de fontes públicas e oficiais. Esta página lista de onde vem cada informação usada no boletim, nas páginas de rio e nos mapas.

Fontes que alimentam a previsão

ANA — Agência Nacional de Águas e Saneamento Básico

Fonte oficial do nível de cada rio monitorado, medido pelas réguas telemétricas a cada ~15 minutos. É a base de tudo — sem ela não há previsão.

ana.gov.br

Open-Meteo

Previsão de chuva (e, em Porto Alegre, também vento e pressão atmosférica) para os próximos dias, usada pra calcular a projeção de nível. Serviço meteorológico open-source, gratuito, sem necessidade de chave de API — a chuva prevista é a média de 3 modelos meteorológicos oficiais.

open-meteo.com

Modelos usados na média

GFS (NOAA, EUA) ECMWF IFS (Europa) ICON (DWD, Alemanha)

Fontes informativas (não entram no cálculo)

INMET — Instituto Nacional de Meteorologia

Avisos meteorológicos oficiais (tempestade, chuva intensa, etc.), mostrados como informação complementar quando ativos para o município de alguma estação monitorada. É só um repasse do aviso oficial — nunca entra em nenhum cálculo do Horizonte.

gov.br/inmet

OpenStreetMap

Mapa de fundo usado nas páginas que mostram a localização física de cada estação de medição. Só ilustrativo — projeto colaborativo de mapeamento livre.

openstreetmap.org

O Horizonte é um projeto pessoal e independente — não tem vínculo com nenhuma das fontes acima, nem com a Defesa Civil. Para alertas oficiais e qualquer decisão de segurança, siga sempre a Defesa Civil do seu município ou estado.
